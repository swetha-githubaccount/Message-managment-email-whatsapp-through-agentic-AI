Multi-Agent Communication System

This project implements a multi-agent communication system where different agents can send notifications via multiple channels. Currently, the system supports:
    📧 Email Agent – Sends automated emails using SMTP.
    💬 WhatsApp Agent – Sends messages through WhatsApp using Twilio Sandbox.

Features:
    Send custom email notifications.
    Send WhatsApp notifications via Twilio.
    Easy to extend for more agents.
    Works seamlessly in Google Colab / local Python environment.

🛠️ Tech Stack:
    -> Python 3.10+
    -> Twilio API (for WhatsApp)
    -> SMTP (for Email)

    dotenv for environment configuration
